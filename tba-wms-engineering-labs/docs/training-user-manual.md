# Training and User Manual

## Dashboard

Use the dashboard first during shift review or go-live support. The KPI cards summarize operational pressure points and the exception table explains what needs attention.

## Operations Page

Use Operations to review:
- inventory availability and reorder risk
- work-order status and due time
- pick-task execution and exceptions

When discussing a warehouse issue, use the acceptance criteria column to connect the technical issue back to the expected business behavior.

## Service Desk Page

Use Service Desk to compare current ticket priority with the recommended triage priority. The recommendation is based on issue wording and ticket age. It is a support aid, not an automatic decision.

## Go-Live Page

Use Go-Live to review readiness by area, owner, status, and target date. At-risk items should be discussed before go-live or shift handover.

## Suggested Operating Rhythm

- Morning: review dashboard and overdue work orders.
- During support: open Service Desk for triage and next actions.
- Before change release: review acceptance criteria and test evidence.
- Before go-live: review readiness score and at-risk items.
